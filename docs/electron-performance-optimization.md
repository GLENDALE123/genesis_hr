# Electron 앱 성능 최적화 가이드

Electron 앱이 가볍고 메모리/디스크 사용을 적절히 관리하도록 최적화된 설정입니다.

## 메모리 최적화

### 1. **메모리 사용량 제한**
- **최대 메모리 사용량**: 30MB (이전: 50MB)
- **최대 캐시 항목 수**: 500개 (이전: 1000개)
- 메모리 사용량이 한도를 초과하면 자동으로 LRU 캐시 정리

### 2. **자동 메모리 정리**
- **정리 주기**: 30분마다 (이전: 1시간)
- 메모리 사용량 모니터링: 5분마다
- 메모리 압박 시 자동 캐시 정리:
  - 120% 초과: 30% 캐시 제거
  - 150% 초과: 50% 캐시 제거
  - 기본: 20% 캐시 제거

### 3. **메모리 누수 방지**
- TTL 기반 캐시 자동 만료 (3일)
- LRU (Least Recently Used) 알고리즘으로 오래된 항목 제거
- 앱 종료 시 모든 캐시 자동 정리

## 디스크 사용 최적화

### 1. **디스크 캐시 크기 제한**
- **최대 디스크 캐시**: 100MB
- 디스크 캐시가 100MB를 초과하면 자동으로 오래된 캐시부터 제거
- 목표 크기: 70MB (30% 여유 공간 유지)

### 2. **캐시 TTL (Time To Live) 단축**
- **기본 TTL**: 3일 (이전: 7일)
- 오래된 캐시 파일 자동 삭제
- 디스크 공간 절약

### 3. **Firebase Storage 캐시 제한**
- **최대 Storage 캐시**: 200MB
- **Storage 캐시 TTL**: 3일
- 오래된 이미지/파일 캐시 자동 정리

### 4. **자동 디스크 정리**
- 캐시 정리 주기: 30분마다
- 만료된 파일 자동 삭제
- 디스크 공간 모니터링

## 설정 값

### 메모리 설정 (`electron/main.js`)

```javascript
const CACHE_CONFIG = {
  MAX_SIZE: 500,                     // 최대 캐시 항목 수
  MAX_MEMORY_MB: 30,                 // 최대 메모리 사용량 (MB)
  MAX_DISK_MB: 100,                  // 최대 디스크 캐시 크기 (MB)
  DEFAULT_TTL: 3 * 24 * 60 * 60 * 1000, // 기본 TTL: 3일
  CLEANUP_INTERVAL: 30 * 60 * 1000,  // 정리 주기: 30분
  SAVE_INTERVAL: 10 * 60 * 1000,     // 저장 주기: 10분
};
```

### Firebase Storage 캐시 설정 (`electron/firebase-optimizer.js`)

```javascript
const FIREBASE_OPTIMIZATION_CONFIG = {
  MAX_STORAGE_CACHE_MB: 200,         // 최대 Storage 캐시 (MB)
  STORAGE_CACHE_TTL: 3 * 24 * 60 * 60 * 1000, // Storage 캐시 TTL: 3일
};
```

## 자동 정리 기능

### 1. **캐시 자동 정리**
- 만료된 캐시 자동 삭제
- 크기 제한 초과 시 오래된 항목부터 제거
- 메모리 압박 시 즉시 정리

### 2. **디스크 공간 관리**
- 디스크 캐시 크기 모니터링
- 크기 제한 초과 시 자동 정리
- 불필요한 파일 자동 삭제

### 3. **성능 모니터링**
- 메모리 사용량 실시간 모니터링
- 디스크 사용량 추적
- 자동 최적화 실행

## 성능 최적화 효과

### 메모리 사용량
- **이전**: 최대 50MB + 무제한 증가 가능
- **개선**: 최대 30MB + 자동 정리로 안정적 유지

### 디스크 사용량
- **이전**: 무제한 증가 가능
- **개선**: 최대 300MB (캐시 100MB + Storage 200MB)로 제한

### 응답 속도
- 더 작은 캐시로 메모리 접근 속도 향상
- 주기적 정리로 메모리 단편화 방지

## 수동 정리 방법

### 캐시 수동 정리

앱 내에서 캐시를 수동으로 정리할 수 있습니다 (향후 구현 가능):
- 설정 메뉴에서 "캐시 정리" 옵션
- 디스크 사용량 표시
- 각 캐시 타입별 개별 정리

### 디스크 공간 확인

캐시 디렉토리 위치:
- Windows: `%APPDATA%\TMS-Integrated-Management\cache\`
- macOS: `~/Library/Application Support/TMS-Integrated-Management/cache/`
- Linux: `~/.config/TMS-Integrated-Management/cache/`

## 추가 최적화 팁

### 1. **불필요한 기능 비활성화**
- 사용하지 않는 개발자 도구 비활성화
- 디버그 로그 최소화

### 2. **이미지 최적화**
- 이미지 파일 크기 최소화
- 썸네일 사용으로 전체 이미지 로드 방지

### 3. **네트워크 최적화**
- 필요한 데이터만 요청
- 배치 요청으로 네트워크 호출 감소

- 디스크 사용량

## 문제 해결

### 메모리 사용량이 계속 높은 경우

1. 캐시 설정 확인
2. 다른 프로세스와의 충돌 확인
3. 메모리 누수 확인 (개발자 도구)

### 디스크 사용량이 계속 증가하는 경우

1. 캐시 디렉토리 확인
2. 수동 캐시 정리
3. 디스크 공간 확인
