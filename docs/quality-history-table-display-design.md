# 종합관리테이블 품질이력 표시 설계

## 🎯 목표

종합관리테이블 페이지에서 제품별 품질이력을 **한눈에 보기 쉽게** 표시하면서도 **중요한 정보를 놓치지 않도록** 설계

## 📊 표시해야 할 핵심 정보

### 1. **최우선 정보** (즉시 확인 필요)
- ✅ **검사 타입별 건수**: 수입/공정/출하 검사가 각각 몇 건인지
- ✅ **최근 검사 결과**: 가장 최근 검사의 결과 (합격/불합격/한도대기 등)
- ✅ **불량률**: 전체 불량률 (불합격 + 한도대기)
- ⚠️ **경고 표시**: 불량률이 높거나 주의가 필요한 경우

### 2. **중요 정보** (상세 확인 필요)
- 📝 **공정검사이력 요약**: 공정검사이력에서 불량률, 불량 유형 추출
- 🔑 **주요 불량 패턴**: 자주 발생하는 키워드 페어 (공정-불량)
- 📅 **최근 검사일**: 가장 최근 검사 날짜
- 🖼️ **이미지 유무**: 이미지가 있는 검사 수

### 3. **상세 정보** (확장/모달에서 확인)
- 전체 검사 이력 목록
- 날짜별 그룹화된 상세 정보
- 각 검사의 전체 내용

## 🎨 UI 설계

### 옵션 1: 컴팩트 뱃지 방식 (개선안 - 평균/트렌드 포함)

```
┌─────────────────────────────────────────────────────────┐
│ [품질이력]                                              │
│ ┌───────────────────────────────────────────────────┐   │
│ │ 📊 전체: 10건 | 불량률: 20% ⚠️ | 평균: 15%      │   │
│ │ ────────────────────────────────────────────────  │   │
│ │ [수입:3 합격] [공정:5 ⚠️불합격] [출하:2 합격]    │   │
│ │ ────────────────────────────────────────────────  │   │
│ │ 📈 트렌드: ↗️ 개선 (20% → 15%)                    │   │
│ │ 🔧 공정이력: 48개중 11개 불량(22%) - 이물, 기름  │   │
│ │ 🔑 주요불량: 사출→기름(5) 증착→이물(4)           │   │
│ │ 📅 최근: 2025-11-24 (공정검사)                   │   │
│ └───────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

**개선된 정보 표시**:
- ✅ **전체 통계**: 총 검사 수, 현재 불량률, 평균 불량률 (한 줄에 모두 표시)
- ✅ **타입별 상태**: 각 검사 타입별 건수와 최근 결과 (색상 코딩으로 즉시 파악)
- ✅ **트렌드**: 최근 불량률 변화 추이 (개선↘️/악화↗️/유지→) - 평균과 비교하여 개선/악화 판단
- ✅ **공정검사이력 요약**: 불량률과 불량 유형 (중요!) - 실제 데이터 패턴 기반 추출
- ✅ **주요 불량 패턴**: 자주 발생하는 키워드 페어 (상위 3개)
- ✅ **최근 검사일**: 가장 최근 검사 정보 (타입 포함)

**핵심 개선점**:
1. **평균 불량률 표시**: 현재 불량률과 평균을 비교하여 개선/악화 판단
2. **트렌드 시각화**: 화살표 아이콘으로 직관적 표시
3. **공정검사이력 자동 추출**: 텍스트에서 불량률과 불량 유형 자동 파싱
4. **색상 코딩**: 불량률에 따라 색상 자동 변경 (0-5%: 초록, 5-10%: 노랑, 10-20%: 주황, 20%+: 빨강)

**장점**:
- 한눈에 모든 정보 확인 가능
- 평균과 트렌드를 통해 개선/악화 파악
- 공간 효율적이면서도 정보가 풍부
- 색상 코딩으로 상태 파악 용이
- 공정검사이력 등 중요한 정보 강조

**단점**:
- 텍스트가 많아서 작은 화면에서는 줄바꿈 필요
- 정보 밀도가 높아 초보자에게는 복잡할 수 있음

### 옵션 2: 아이콘 + 숫자 + 툴팁 방식

```
┌─────────────────────────────────────────┐
│ [품질이력]                              │
│ 📋 수입:3  🔧 공정:5  📦 출하:2        │
│ ⚠️ 불량률: 20%                          │
│ [상세보기] 버튼                         │
└─────────────────────────────────────────┘
```

**장점**:
- 매우 컴팩트
- 호버 시 툴팁으로 상세 정보 표시
- 확장 가능

**단점**:
- 상세 정보 확인을 위해 호버 필요
- 모바일에서 툴팁 사용 불편

- 공간 효율적
- 모바일 친화적

## 🎨 색상 코딩 전략

### 검사 결과별 색상
- **합격**: 초록색 (green-500)
- **불합격**: 빨간색 (red-500)
- **한도대기**: 주황색 (orange-500)
- **한도승인**: 노란색 (yellow-500)
- **반출**: 파란색 (blue-500)
- **미등록**: 회색 (gray-400)

### 불량률별 경고 레벨
- **0-5%**: 정상 (초록)
- **5-10%**: 주의 (노랑)
- **10-20%**: 경고 (주황)
- **20% 이상**: 위험 (빨강)

```tsx
<div className="space-y-1">
  {/* 검사 타입별 건수 및 최근 결과 */}
  <div className="flex items-center gap-2 flex-wrap">
    <Badge variant={incomingResult === '합격' ? 'default' : 'destructive'} className="text-xs">

    </Badge>
    <Badge variant={inProcessResult === '합격' ? 'secondary' : 'destructive'} className="text-xs">
      공정:{inProcessCount} {latestInProcess?.result || ''}
    </Badge>
    <Badge variant={outgoingResult === '합격' ? 'outline' : 'destructive'} className="text-xs">
      출하:{outgoingCount} {latestOutgoing?.result || ''}
    </Badge>
  </div>
  
  {/* 불량률 및 경고 */}
  <div className="flex items-center gap-2">
    <span className={`text-xs font-semibold ${
      defectRate >= 20 ? 'text-red-600' :
      defectRate >= 10 ? 'text-orange-600' :
      defectRate >= 5 ? 'text-yellow-600' :
      'text-green-600'

      공정: {extractHistorySummary(latestInProcessHistory)}

  {/* 확장 버튼 */}
  <Button variant="ghost" size="sm" className="h-6 text-xs">

  </Button>
```

## 🔍 공정검사이력 요약 추출 로직

공정검사이력에서 중요한 정보를 추출:

```typescript
function extractHistorySummary(history: string): string {
  // 패턴 1: "검사 48개중 불량 11개 불량율 22%"
  const pattern1 = /검사\s*(\d+)개중\s*불량\s*(\d+)개.*?불량율\s*([\d.]+)%/;
  const match1 = history.match(pattern1);
  if (match1) {
    return `${match1[1]}개중 ${match1[2]}개 불량(${match1[3]}%)`;
  }
  
  // 패턴 2: "360검사중 불량16 불량율 0.04%"
  const pattern2 = /(\d+)검사중\s*불량(\d+).*?불량율\s*([\d.]+)%/;
  const match2 = history.match(pattern2);
  if (match2) {
    return `${match2[1]}개중 ${match2[2]}개 불량(${match2[3]}%)`;
  }
  
  // 패턴 3: 불량 유형 추출 "불량유형 이물, 기름"
  const defectTypes = history.match(/불량유형\s*[:：]?\s*([^%\n]+)/);
  if (defectTypes) {
    return `불량: ${defectTypes[1].trim()}`;
  }
  
  // 기본: 처음 30자만
  return history.substring(0, 30) + (history.length > 30 ? '...' : '');
}
```

## 📱 반응형 고려사항

### 데스크톱 (>1024px)
- 품질이력 셀에 모든 정보 표시
- 확장 패널로 상세 정보 표시

### 태블릿 (768px-1024px)
- 핵심 정보만 표시 (건수, 불량률)
- 공정검사이력 요약은 툴팁으로

### 모바일 (<768px)
- 최소한의 정보만 (건수, 불량률)
- 클릭 시 모달로 상세 정보 표시

## 🎯 구현 우선순위

### Phase 1: 기본 표시 (필수)
1. ✅ 검사 타입별 건수 표시
2. ✅ 최근 검사 결과 표시
3. ✅ 불량률 계산 및 표시
4. ✅ 색상 코딩 (결과별, 불량률별)

### Phase 2: 공정검사이력 요약 (중요)
1. ✅ 공정검사이력에서 불량률 추출
2. ✅ 불량 유형 추출
3. ✅ 요약 텍스트 생성

### Phase 3: 상세 정보 (선택)
1. 확장 패널 구현
2. 주요 불량 패턴 표시
3. 최근 검사 목록 표시

## 💡 추가 고려사항

### 1. 성능 최적화
- 품질이력이 많은 제품의 경우 가상화 고려
- 요약 정보는 메모이제이션

### 2. 접근성
- 스크린 리더를 위한 aria-label
- 키보드 네비게이션 지원

### 3. 사용자 경험
- 로딩 상태 표시
- 빈 데이터 처리
- 에러 상태 처리

```tsx
interface QualityHistorySummary {

  incoming: { count: number; latestResult?: string };
  inProcess: { count: number; latestResult?: string; historySummary?: string };
  outgoing: { count: number; latestResult?: string };
  
  // 불량률
  defectRate: number;
  
  // 주요 불량 패턴 (상위 3개)
  topDefectPatterns: Array<{ process: string; defect: string; count: number }>;
  
  // 최근 검사일
  latestInspectionDate: string;
  
  // 경고 레벨
  warningLevel: 'normal' | 'caution' | 'warning' | 'danger';
}
```
