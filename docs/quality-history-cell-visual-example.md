# 품질이력 셀 시각적 예시

## 🎨 최종 UI 예시

### 기본 표시 (항상 보임)

```
┌─────────────────────────────────────────────────────────────┐
│ 📊 전체: 10건 | 불량률: 20% ⚠️ | 평균: 15% | ↑ 5.0%p      │
│                                                              │
│ [수입:3 합격] [공정:5 ⚠️불합격] [출하:2 합격]              │
│                                                              │
│ 📈 트렌드: ↘️ 개선 (25% → 20%)                              │
│                                                              │
│ 🔧 공정이력: 48개중 11개 불량(22%) - 이물, 기름            │
│                                                              │
│ 🔑 주요불량: 사출→기름(5), 증착→이물(4), 코팅→얼룩(2)      │
│                                                              │
│ 📅 최근: 2025-11-24 (공정검사)                             │
│                                                              │
│ [▼ 상세보기]                                                │
└─────────────────────────────────────────────────────────────┘
```

## 📊 표시되는 정보 설명

### 1. 전체 통계 라인
```
📊 전체: 10건 | 불량률: 20% ⚠️ | 평균: 15% | ↑ 5.0%p
```
- **전체 건수**: 총 검사 수
- **현재 불량률**: 전체 불량률 (색상 코딩)
- **평균 불량률**: 최근 10건 기준 평균
- **평균 대비 차이**: 현재가 평균보다 높으면 ↑ 빨강, 낮으면 ↓ 초록

### 2. 타입별 뱃지
```
[수입:3 합격] [공정:5 ⚠️불합격] [출하:2 합격]
```
- 각 검사 타입별 건수와 최근 결과
- 색상 코딩: 합격(초록), 불합격(빨강), 한도대기(주황)

### 3. 트렌드
```
📈 트렌드: ↘️ 개선 (25% → 20%)
```
- 최근 3건 vs 이전 3건 비교
- 개선(초록 ↘️), 악화(빨강 ↗️), 유지(회색 →)

### 4. 공정검사이력 요약 (중요!)
```
🔧 공정이력: 48개중 11개 불량(22%) - 이물, 기름
```
- 공정검사이력 텍스트에서 자동 추출
- 불량률과 불량 유형을 한눈에 확인

### 5. 주요 불량 패턴
```
🔑 주요불량: 사출→기름(5), 증착→이물(4), 코팅→얼룩(2)
```
- 자주 발생하는 키워드 페어 상위 3개
- 빈도순으로 정렬

### 6. 최근 검사일
```
📅 최근: 2025-11-24 (공정검사)
```
- 가장 최근 검사 날짜와 타입

## 🎨 색상 코딩

### 불량률별 색상
- **0-5%**: 초록색 (정상)
- **5-10%**: 노란색 (주의)
- **10-20%**: 주황색 (경고)
- **20% 이상**: 빨간색 (위험)

### 트렌드 색상
- **개선 (↓)**: 초록색
- **악화 (↑)**: 빨간색
- **유지**: 회색

### 평균 대비 색상
- **평균보다 높음 (↑)**: 빨간색
- **평균보다 낮음 (↓)**: 초록색

## 💡 핵심 개선 사항

1. **평균 불량률 표시**: 현재와 평균을 비교하여 개선/악화 판단
2. **트렌드 시각화**: 화살표와 색상으로 직관적 표시
3. **공정검사이력 자동 추출**: 텍스트에서 불량률과 불량 유형 자동 파싱
4. **색상 코딩**: 불량률에 따라 색상 자동 변경
5. **컴팩트하면서도 정보 풍부**: 한눈에 모든 정보 확인 가능

## 📱 반응형 고려

### 데스크톱
- 모든 정보 표시
- 확장 패널로 상세 정보

### 태블릿/모바일
- 핵심 정보만 표시 (건수, 불량률, 평균)
- 클릭 시 모달로 상세 정보
